## What this repository is

This is the source of that record — the code the live record runs, not a demo of it and
not a template. It is public so that anybody who is asked to trust the record can read the
thing they are being asked to trust, instead of taking a page's word for it.

- `src/` — the record as it is read: its pages, its rooms, its reading type and its marks.
- `base44/` — the record's tables, the server functions that read and write them, its
  automations, and the words of the emails it sends.
- `public/` — the files served as they are.

## The two licences

Two layers, both open, and both given for good: a licence of this kind cannot be taken back,
by this record or by anyone who takes it over.

- **The code** is under the **GNU AGPL-3.0** — see [`LICENSE`](LICENSE). If you run a
  modified version as a service for other people, the changes you made go back out under
  the same licence. That is the one condition, and it is what stops the classic extraction
  play: take free code, close it, add tracking, sell it.
- **The words** — every published entry, its source and its corrections — are under
  **Creative Commons BY-SA 4.0** — see [`CONTENT_LICENSE.md`](CONTENT_LICENSE.md). Take
  them, change them, print them, sell them. Keep the name on them, and let whatever you
  make be this free too.

## Checking it rather than trusting it

The record argues that a claim is worth exactly as much as the check you can run on it, so:

- Every entry carries its own source, and the record keeps a public corrections page.
- Every entry can be fingerprinted and checked in your own browser, at
  <https://uf51.love/seals>.
- Every privacy claim is written down and can be read at <https://uf51.love/ClimatePrivacy>.

## What is not here

The record's own trust: the years of entries, the review trail behind each one, the outcome
data and the readers who rely on it. A copy of this repository begins with none of that. The
code can be copied; the name, and the trust placed in it, cannot be taken along with it.
Anyone building on this starts under their own name, in the open, from zero.
